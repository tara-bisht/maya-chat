# Public custom agents are a house listing

Studio exists on Free, but privacy is a paid seat. A public custom agent is discoverable and chattable by any signed-in user; conversations and memories stay `(user_id, agent_id)`. This is not a marketplace: no payouts, no remix of someone else’s backstory, no storefront.

Free seed cap is 3, all public. Plus is 10, public or private. Pro is unlimited. On downgrade, existing private rows stay private; Free cannot create new private roles or flip public to private.

The PRD originally said Free custom = 0 and listed a community marketplace as out of MVP. Those two facts would have made “Free can only create public agents” meaningless. House listing is the growth path that keeps marketplace out.
