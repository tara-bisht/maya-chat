# Chrome uses the same words as other AI apps

The wall can still look like a night repertory. Buttons, pickers, and forms cannot. New users already know **Agent**, **Chat**, **Model**, **Instructions**, **Memory**, **Plan**, and **Credits** from ChatGPT, Claude, Gemini, and Character.AI.

**Voice** (for the LLM), **House**, **playbill**, **costume**, and **backstory** stay in design docs and code folder names. They do not appear in chrome. The model picker reads **Model: grok**, not “Voice through grok.” Create-agent fields are Name, Description, Instructions, Color, Tone, Tools.
